本文档对测试引擎模块 assets 目录下的说明文档进行索引和简要说明。

## 目录结构

```

└── assets/
    └── engin相关说明(按需了解即可)/
        ├── PRD.md                      # 产品需求文档
        ├── 业务逻辑设计.md               # 核心执行逻辑
        ├── 功能模块设计.md               # 模块功能划分
        ├── 系统功能结构图.md             # 系统架构
        ├── 系统设计说明书.md             # 详细设计说明

            ├── case_result.json         # 结果数据结构示例

```

## 核心功能说明

### 1. 引擎启动流程
- 配置加载 → 心跳连接 → WebSocket监听 → 任务拉取

### 2. 任务执行流程
- 任务接收 → 数据下载 → 解压解析 → 并发执行 → 结果上传

### 3. 用例执行流程
- 前置处理 → 步骤执行 → 断言验证 → 参数提取 → 后置处理

## 快速定位

- **理解执行逻辑** → `业务逻辑设计.md`
- **查看数据格式** → `补充（数据详情）/json数据设计及示例.md`
- **了解模块设计** → `功能模块设计.md`
